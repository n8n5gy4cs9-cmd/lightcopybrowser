# Session plan

| Session | Name | Outcome |
|---:|---|---|
| 1 | Foundation and browser shell | Buildable Android/Compose project and polished static one-handed shell |
| 2 | Secure single-tab browsing | Real WebView navigation, address/search parsing, progress, errors, back/forward/reload |
| 3 | One-tap source and text | Original HTML capture, rendered text/DOM extraction, clipboard feedback, viewers |
| 4 | Console and log export | Full bounded console capture, filters, copy/clear/export, floating console access |
| 5 | Fullscreen system | Immersive mode plus configurable/drag-save exit button |
| 6 | Advanced copy and inspector | URL/title/links/images/Markdown copy and safe element inspection |
| 7 | Page info and storage | Metadata, SSL/load/viewport, cookies and Web Storage viewers/actions |
| 8 | Network log and dev toggles | Request log, JS/ad-block/user-agent per-tab controls |
| 9 | Tabs, incognito, and find | Multi-tab lifecycle, private sessions, find-in-page |
| 10 | Reader, screenshots, and save | Reader/dark transforms, full-page capture, HTML/TXT saving |
| 11 | History, bookmarks, downloads, share, QR | Local browser utilities and Android integrations |
| 12 | Developer settings | Complete typed settings UI, injection, import/export, download folder |
| 13 | Hardening and release | Accessibility, process restore, performance, privacy, size, release verification |

Each detailed brief under `docs/sessions/` is binding for its session. Product requirements remain canonical in `docs/product-spec.md`.
